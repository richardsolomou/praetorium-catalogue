# Praetorium catalogue

Source pins, composition and authored corrections live in `catalogue/`. Fetched sources and generated files stay outside Git. Application behaviour and saved-roster migrations remain in [Praetorium](https://github.com/richardsolomou/praetorium.gg).

Generated catalogue releases are mirrored on GitHub Releases and R2. Applications install an exact checksummed release locally; no lookup depends on either host.
